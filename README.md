# 🏋️ Squat AI Coach

스마트폰 카메라와 AI 포즈 추정 기술을 활용하여 스쿼트 자세를 실시간으로 분석하고 피드백을 제공하는 AI 코치 시스템입니다.

---

## 📌 프로젝트 개요

별도의 고가 장비 없이 스마트폰 카메라만으로 스쿼트 자세를 실시간 분석하고, 6가지 자세 유형을 자동으로 분류하여 즉각적인 피드백을 제공합니다.

---

## 🎯 자세 분류 클래스

| 클래스 | 설명 |
|--------|------|
| Good Squat | 올바른 스쿼트 |
| Shallow Squat | 얕은 스쿼트 |
| Forward Lean | 앞으로 기울어진 스쿼트 |
| Knee Cave | 무릎 안쪽 꺾임 |
| Heel Rise | 발뒤꿈치 들림 |
| Asymmetric | 비대칭 스쿼트 |

---

## 📊 모델 성능

| 모델 | 정확도 | Macro F1 |
|------|--------|----------|
| RandomForest | 96.43% | 0.97 |
| XGBoost | 97.30% | 0.97 |

## 🚀 사용 방법

### 1. 모델 학습 (Google Colab)
`최종.ipynb`를 Colab에서 실행하여 모델을 학습하고 `.pkl` 파일을 다운로드합니다.

### 2. 핸드폰 카메라 연결
1. 핸드폰에 **DroidCam** 앱 설치
2. PC에 **DroidCam Client** 설치
3. 같은 Wi-Fi에서 앱 실행 후 IP 주소로 연결

### 3. 실시간 분석 실행
```bash
python realtime.py
```

- 화면에 자세 분류 결과, 관절 각도, 반복 횟수가 실시간으로 표시됩니다.
- `q` 키를 누르면 종료됩니다.
